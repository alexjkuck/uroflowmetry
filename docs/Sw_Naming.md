

Naming:

FIRMWARE
    Uroflow_FW_Acquire -- ESP32 firmware that is used to read from the load cells 
                          and flow sensora and output the data on the serial port.
    Uroflow_FW_Simulate -- ESP32 firmware that outputs synthatic load cell and flow sensor data.

SOFTWARE
    Uroflow_Studio -- Python sw that reads serial ESP32 data and displays/stores it. Later it
                      might also be used to implement the algorithms/ML to estimate uroflometry metrics.
Uroflow_Synth -- Python sw that simulates uroflowmetry waveforms that can be used to develop/test
                 the estimation algorithms/ML.
    
Uroflow_Lab -- Python sw that reads the files generated by Uroflow_Synth and then has a place to 
                develop/test algorithms and/or ML to estimate uroflometry metrics.
